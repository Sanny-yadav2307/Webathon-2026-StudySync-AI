# 🧠 StudySync AI

Transform your study materials into smart summaries, interactive quizzes, and instant document chat for WebNova 2026.

## 🚀 Overview
StudySync AI ek advanced AI-powered study platform hai jo students aur learners ko heavy PDF documents aur study materials se turant smart summaries, dynamic multiple-choice questions (MCQs), aur interactive document chat generate karke deta hai. Iska maqsad padhai ko smart, fast aur engaging banana hai.

## 🛠️ Tech Stack
- **Frontend:** Next.js (React), Tailwind CSS
- **Backend:** FastAPI, Python, `pypdf`
- **AI Model:** Google GenAI SDK (`gemini-3.8-flash`)

## ✨ Key Features
- **Smart Document Analysis:** PDF text extraction aur structured executive summaries.
- **Interactive Mock Tests:** Automatic MCQ generation with instant answer evaluation, explanations, and score tracking.
- **Chat with Document (AI Assistant):** PDF context ke adhar par real-time Q&A.
- **Study Notes Export:** Generated summary aur quizzes ko formatted Study Notes (.html) ke roop mein download karne ki suvidha.
- **Data Persistence:** LocalStorage integration taaki page refresh hone par bhi chat aur analysis history safe rahe.
- **Resilient Architecture:** Automatic retry logic (exponential backoff) to handle API rate limits and 503 errors smoothly.
